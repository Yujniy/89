# Winter Cup — HTML-виджет для Telegram (Bot API 10.4)

Интерактивный анонс турнира, который рендерится прямо в пузыре сообщения
(метод `sendWidget`, без Mini App).

- `winter_cup.html` — сам виджет: canvas, пиксель-арт, 2 слайда, свайп вбок / тап.
- `send_widget.py` — отправка: `BOT_TOKEN=... CHAT_ID=... python send_widget.py`
- `check_size.py` — проверка лимитов (32 КБ UTF-8, 4 КБ zlib-9).
- `preview.html` — локальный просмотр в браузере (`?s=2` — второй слайд).

В проде виджеты сейчас доставляются только в личные чаты с ботом, пересылка
и copyMessage недоступны. Для рассылки анонса отправляйте `sendWidget`
каждому подписчику по его `user_id`.
